The site and Android app now read stable release notes from the same GitHub Release description.

## Release notes

- Headings, lists, emphasis, links, tables, and code blocks are displayed as Markdown.
- **Show new release notes automatically** is checked by default below **Mark as read**. The archive remains available from the main menu.
- Downloaded release notes can still be read offline.

## Interface

- Pixel Workshop uses stepped corners on its cards and layered buttons.
- The navigation and settings buttons have more space between them.

## Project site

The site uses Notier’s light palette. Release cards are centered on mobile, with separate buttons for GitHub and APK downloads.
