## Device and Google Drive galleries

- Choose a device folder and a Google Drive folder separately under **Settings → Gallery**. Use images from both in the same note.
- Add images to the selected folder with your file manager or Google Drive. Refresh the gallery in Notier and search by filename.
- The editor’s image button offers **Insert image URL** and **Insert from gallery**. Tap an image to insert the Markdown reference at the cursor. Selected text becomes the image description.

## Pixel Workshop

- Cards and dialogs have more defined stepped corners. Buttons have a layered face and a pressed state.
- The Markdown preview uses the Lucide copy icon.

## Website and release notes

- The mobile site includes gallery setup instructions.
- Android and the website fetch release notes from GitHub Releases and retain the last successful response. Edits appear after the next check.
