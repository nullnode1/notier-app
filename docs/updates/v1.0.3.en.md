# Jump to headings and explore languages

Notier v1.0.3 added a table of contents to Markdown preview. On long notes, tap its icon to jump straight to a heading.

## New languages and scripts

The release added several Kazakh and Uzbek scripts, plus Kyrgyz, Azerbaijani, Turkmen, Tajik, Dari, and Pashto.

## Update checks

Notier started checking GitHub Releases for stable Android APKs. You can enable update notifications in Settings.
