# Notier v1.0.5

Notier now reads stable Android releases and their notes from GitHub.

- **Live release notes.** Open the GitHub Releases archive from the main menu. Downloaded notes remain readable offline.
- **Release announcements.** Read the latest notes in the app. Mark them as read or show them again at the next launch.
- **Welcome screen.** Choose a theme and language, read release notes, or check for updates.
- **Pixel Workshop.** A theme with square panels, layered green buttons, and new pixel icons.
- **Layout and project site.** Notes open with a subtle transition. Controls and menus adapt to narrow screens, and the GitHub Pages site has a mobile layout.

Download the signed APK from this release. Notier supports Android 8 and later.
