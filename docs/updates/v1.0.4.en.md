# Updates and new pixel icons

Notier v1.0.4 keeps your local notes available as usual. You can also read the last update result and these release notes offline.

## Update from GitHub

The Updates screen shows when Notier last checked successfully. When a new Android release is available, you can download its APK or open the GitHub release. Your last result stays on your device when you lose your connection.

## Blocky pixel icons

The pixel set uses crisp, colorful vectors for folders, notes, search, editing, and more. Change the icon style in Settings.

## Read the release notes again

This page appears the first time you open a new version. You can revisit it from the main menu or the Updates screen. Open the release notes archive for earlier versions.
